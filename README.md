# КиноКлуб — Системный английский по фильмам

Рабочий прототип сайта для проекта Людмилы Мандель: кинетическая заставка, четыре кинематографичных экрана, каталог, фильтры, поиск, видеоплеер, вход, регистрация, настройка языков/качества и форма обратной связи.

## Запуск

1. Установить Node.js 20+.
2. Перейти в эту папку (`cd kinoclub_site`).
3. Запустить `npm start` (без `npm install`: внешних серверных библиотек нет).
4. Открыть `http://localhost:3000`.

Вход и регистрация обрабатываются сервером, пароли хешируются с помощью `scrypt`, сессии хранятся в HttpOnly cookie. Сообщения пользователей сохраняются в `data/db.json`. Файл не доступен из публичной папки.

**Важно:** на бесплатных ephemeral-хостингах локальная папка `data` может удаляться при перезапуске/переразвертывании. Для **публичного запуска с реальными пользователями** обязательно настройте постоянное хранилище (`DATA_DIR` указывает на примонтированный сохраняемый диск), защиту данных, резервное копирование, согласие на обработку персональных данных, email-подтверждение/восстановление пароля и рабочий процесс обработки обратной связи. Эту версию разумно сначала публиковать как закрытую демонстрацию, пока не подключена production-БД.

## Видеоконтент

В четырех экранных карточках стоят превью и YouTube-встраивания **публичных трейлеров**, а не скопированные фрагменты полнометражных фильмов:

- «Детство Шелдона»: CBS — `https://www.youtube.com/watch?v=XR-jIhwIfIw`.
- «Блондинка в законе»: MGM Studios — `https://www.youtube.com/watch?v=vWOHwI_FgAo`.
- «Предложение»: Rotten Tomatoes Classic Trailers — `https://www.youtube.com/watch?v=jHraHCjK094`.
- «Тед Лассо»: Apple TV — `https://www.youtube.com/watch?v=GACU1N9hg5o`.

Возможность воспроизведения регулируется YouTube и правообладателями. Карточки могут показывать статичное превью, если интернет недоступен или запрещено встраивание. Озвучку и качество внешнего видео контролирует сам YouTube.

Для **настоящих учебных фрагментов и управления аудиодорожкой/качеством** нужны законно полученные исходные файлы и отдельные версии медиа, после чего можно добавить собственный HTML5-плеер. Трейлеры на этом сайте не загружаются на сервер и не обходят защиту потоковых сервисов.

## Важные файлы

- `public/index.html`: сайт, экраны, модальные окна.
- `public/styles.css`: стили и анимация.
- `public/app.js`: каталог, интерфейс, плеер, настройки и авторизация.
- `public/assets/kinoclub-logo.png`: подготовленный из вашего файла логотип с прозрачным фоном.
- `server.js`: Node HTTP-сервер и API.
- `data/`: создается для хранения учетных записей и сообщений, не публиковать.

## Быстрый визуальный просмотр

Откройте отдельный файл `kinoclub-preview.html`, который прилагается к архиву: он демонстрирует анимации, экраны, каталог и меню без установки Node.js. Вход и отправка обратной связи в нем отключены, поскольку для них требуется сервер.

## Размещение

Сервис типа Node Web Service, build command `echo ready`, start command `npm start`, Node 20+, HTTPS обязателен. Перед открытием регистрации публике требуется постоянное хранилище и возможность делать резервные копии.

## Отдельный GitHub-репозиторий

Проект подготовлен для отдельного репозитория `kinoclub-cinematic` (ветка `main`).
`render.yaml` позволяет создать самостоятельный веб-сервис Render.
Публичная демонстрационная версия не должна использоваться для хранения важных учетных записей: на бесплатном тарифе Render данные локального JSON-хранилища не гарантированно сохраняются при развертывании.
